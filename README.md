# Landing Page PT Gadai Murah Jogja

Landing page responsif berbasis Next.js untuk PT Gadai Murah Jogja.

## Menjalankan secara lokal

```bash
npm install
npm run dev
```

## Build dan deployment

```bash
npm run build
```

Proyek ini menggunakan `output: 'export'` sehingga hasil statis ada di folder `out/`. Hubungkan repositori ini ke Vercel sebagai proyek Next.js dengan root directory `./` dan build command `npm run build`.

Semua gambar yang dipakai halaman ada di `public/assets/`. Tombol pengajuan dan konsultasi membuka WhatsApp GMJ.
